# Log penggunaan

Folder ini memuat catatan log dan inspeksi yang diambil pada Test Run 15.

- `console_AUT_beranda_dan_produk.txt` - hasil pemeriksaan Console pada beranda, halaman produk, dan keranjang
- `dom-inspection_cart-quantity.txt` - markup kontrol kuantitas keranjang dan baris keranjang

Catatan: tidak ada berkas log error JavaScript karena seluruh cacat yang ditemukan pada TR-15 bersifat
kalkulasi nilai, validasi input, dan aksesibilitas, bukan exception runtime.
