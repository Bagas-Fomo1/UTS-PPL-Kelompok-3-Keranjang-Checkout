# Rekaman layar

Tidak ada berkas rekaman pada Test Run 15.

Aturan pengumpulan menyebutkan rekaman layar wajib untuk cacat yang intermiten atau yang bergantung pada
urutan interaksi. Seluruh 15 eksekusi FAILED pada TR-15 bersifat selalu dapat direproduksi (100%) sehingga
tidak memerlukan rekaman, dan bukti disajikan dalam bentuk tangkapan layar penuh pada folder `screenshots/`
serta lampiran komentar eksekusi di Kiwi TCMS.
